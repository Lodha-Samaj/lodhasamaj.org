# Fonts

Self-hosted from Google Fonts under the SIL Open Font License 1.1. The licence texts are `OFL-Mukta.txt` and `OFL-TiroDevanagariHindi.txt`.

Shipped as woff2, converted from the upstream TTF files by `tools/fetch_fonts.sh`:

- `TiroDevanagariHindi-Regular.woff2` (headings)
- `Mukta-Regular.woff2`, `Mukta-SemiBold.woff2`, `Mukta-Bold.woff2`, `Mukta-ExtraBold.woff2` (body and UI)

The CSS falls back to `serif` and `system-ui` if a file is missing.
